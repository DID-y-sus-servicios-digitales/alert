# Alerts, Confirms and Prompts in Javascript in more beautiful way
Ways of use:
-
+ Alert:  
  ***styled.alert(`content`);***
<hr>
  
+ Prompt:  
  ***let `variable` = await styled.prompt(`content`, `value`)***  
  and if it is inside a function, you have to put 'async' before `function`

<hr>
  
+ Confirm:  
  ***let `variable` = await styled.confirm(`content`, `value of button false`, `value of button true`);***  
  and if it is inside a function, you have to put 'async' before `function`
